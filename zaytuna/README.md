# زيتونة (Zaytuna)

**لغة برمجة عربية** تُترجم 1:1 إلى جافاسكربت (جسر لا جزيرة) + **مصحّح أكواد تلقائي** + **حارس يونيكود** (Trojan Source).
**القاعدة الذهبية:** لا يُكتب أي إصلاح قبل اجتيازه مدقّق اللغة الحقيقي — وإن لم يوجد مدقّق على الجهاز نقول ذلك ولا نكتب.

## تشغيل سريع

```bash
node bin/zaytuna.js مساعدة              # كل الأوامر + جدول اللغات
node bin/zaytuna.js تشغيل examples/حاسبة.zy
node bin/zaytuna.js فحص   examples/كود_به_أخطاء.js
node bin/zaytuna.js إصلاح examples/كود_به_أخطاء.js --tier 1 --write
node bin/zaytuna.js اقترح طالم                 # تصريف ذاتي: التنفيذ مكتوب بزيتونة (selfhost/اقتراح.zy)
node bin/zaytuna.js ترجم examples/حاسبة.zy --إلى بايثون --out حاسبة.py   # زر الترجمة
node bin/zaytuna.js ترجم --لغات                  # أهداف الترجمة وحالة كل واحد
node ui/server.js                        # واجهة ويب: زر «ترجم» + قائمة لغات (بلا مكتبات)
node tests/run.js                       # 74 اختبارًا
node bin/zaytuna.js بناء examples/أنماط_وأنواع.zy --ts   # مخرج تايبسكربت بالأنواع
bash demo/tour.sh                       # جولة عرض (14 خطوة)
node demo/make-transcript.js            # إعادة توليد سجلّ المخرجات الحقيقية
```

## اللغة

```text
متغير الاسم = "سارة"                # نصّ عربي (والكلمات المفتاحية عربية)
ثابت العمر = ٣٠                     # الأرقام العربية تُقبل في الأعداد

دالة جمع(انشر الأعداد) {           # بسط/تجميع
  متغير المجموع = 0
  لكل عدد في الأعداد { المجموع += عدد }
  أرجع المجموع
}

طابق (مجموع) {                     # أنماط مطابقة
  مع ٠:           اطبع("صفر")
  مع ١، ٢، ٣:     اطبع("صغير")
  مع من ٤ إلى ١٠: اطبع("متوسط")
  غير_ذلك:        اطبع("كبير")
}

دالة هوية عام <س>(قيمة: س): س { أرجع قيمة }   # أدوية عامة (تُشطب في JS، تبقى في --ts)
ثابت النتيجة = ٨٧ >= ٥٠ ؟ "ناجح" : "راسب"      # شرط ثلاثي عربي
اطبع(انضم(اقسم("زيتونة-لغة"، "-")، " + "))
```

## زر الترجمة (متعدد الأهداف)

اكتب بالعربية، ثم اختر اللغة التي تريد التحويل إليها:

```bash
zaytuna ترجم examples/حاسبة.zy --إلى بايثون --out حاسبة.py
zaytuna ترجم examples/مرحبا.zy --إلى سي++
node ui/server.js     # أو من الواجهة: قائمة لغات + زر «ترجم»
```

| الهدف | التحقق الفعلي | الحالة |
|---|---|---|
| جافاسكربت · تايبسكربت | `node --check` · `tsc --noEmit` | ✅ |
| **بايثون** | `py_compile` + **تنفيذ فعلي** + مقارنة النتيجة بمخرج جافاسكربت | ✅ نتائج مطابقة حرفيًا |
| **سي++ (C++17)** | `g++ -fsyntax-only` + تجميع وتنفيذ | ✅ جزئيًا — وما لا يُترجم يُقال صريحًا |
| روبي · بي إتش بي | المدقّق غير مثبّت في هذه البيئة | ⚠ مكتوبان وغير متحقَّق منهما |
| سي · جافا · سي شارب · جو · رست | — | ⏳ لاحقًا (السبب مذكور في `--لغات`) |

**القاعدة نفسها:** المترجم يسجّل كل موضع لم يستطع ترجمته (لا يخفي شيئًا)، ويتحقق بمدقّق حقيقي، ويشغّل
المخرج ويقارن نتيجته بجافاسكربت — وإن لم يوجد المدقّق قال «لم أتحقق» ولم يعلن نجاحًا.

**تصريف ذاتي:** `selfhost/اقتراح.zy` — مقترح الكلمات المفتاحية مكتوب بزيتونة ومُترجَم بمترجمها، ومُختبَر على 229 مدخلًا مقابل تنفيذ جافاسكربت (0 اختلافات).

المعجم الكامل والمستويات والضمانات في [`../docs/ARABIC_CODE_SPEC.md`](../docs/ARABIC_CODE_SPEC.md)، والمخرجات الحقيقية في [`../docs/DEMO_TRANSCRIPT.md`](../docs/DEMO_TRANSCRIPT.md).

## الإصلاح

| المستوى | ماذا يفعل |
|---|---|
| 0 | حذف الحروف الخفية (اتجاه/صفرية العرض/وسوم) · `، ؛ ٫ ٬` · أرقام عربية في الأعداد · `؟` في الشرط الثلاثي · تطويل · فصل أرقام الالتصاق |
| 1 | + إعادة تسمية متسقة للأسماء (`متغير١` ← `متغير1` في كل مواضعها) |
| 2 | + نموذج لغوي بحلقة تحقق (`--ai` مع `ZAYTUNA_API_KEY`) — ولا يُطبَّق شيء قبل اجتياز المدقّق |

`إصلاح` يحفظ نسخة `.bak` قبل الكتابة، **ويرفض الكتابة** إن لم يستطع التحقق (إلا بـ `--no-verify` الصريحة).
