# زيتونة (Zaytuna)

**لغة برمجة عربية** تُترجم 1:1 إلى جافاسكربت (جسر لا جزيرة) + **مصحّح أكواد تلقائي** + **حارس يونيكود** (Trojan Source).
**القاعدة الذهبية:** لا يُكتب أي إصلاح قبل اجتيازه مدقّق اللغة الحقيقي — وإن لم يوجد مدقّق على الجهاز نقول ذلك ولا نكتب.

## تشغيل سريع

```bash
node bin/zaytuna.js مساعدة              # كل الأوامر + جدول اللغات
node bin/zaytuna.js تشغيل examples/حاسبة.zy
node bin/zaytuna.js فحص   examples/كود_به_أخطاء.js
node bin/zaytuna.js إصلاح examples/كود_به_أخطاء.js --tier 1 --write
node tests/run.js                       # 55 اختبارًا
bash demo/tour.sh                       # جولة عرض (10 خطوات)
node demo/make-transcript.js            # إعادة توليد سجلّ المخرجات الحقيقية
```

## اللغات المدعومة (17)

| مُتحقَّق منها في هذه البيئة | المدقّق |
|---|---|
| جافاسكربت/نود · بايثون · زيتونة · سي · سي++ · شل · بيرل | `node --check` · `py_compile` · مترجم زيتونة · `gcc/g++ -fsyntax-only` · `bash -n` · `perl -c` |

**معرّفة ومربوطة وتنتظر تثبيت الأداة:** تايبسكربت (`tsc`) · جافا (`javac`) · سي شارب (`dotnet`) · جو (`gofmt`) · رست (`rustc`) · بي إتش بي (`php -l`) · روبي (`ruby -c`) · سويفت (`swiftc -parse`) · كوتلن (`kotlinc`) · SQL (لا نُشغّله — أمان).

## اللغة

```text
دالة جمع(انشر الأعداد) {           # بسط/تجميع
  متغير المجموع = 0
  لكل عدد في الأعداد { المجموع += عدد }
  أرجع المجموع
}

اختر (٨٧) {                        # switch عربي
  حالة ٩٠: اطبع("ممتاز") كسر
  غير_ذلك: اطبع("قريب")
}

ثابت الضاعف = (س) ⟶ س * 2          # دالة سهمية
اطبع(انضم(اقسم("زيتونة-لغة"، "-")، " + "))
```

المعجم الكامل والمستويات والضمانات في [`../docs/ARABIC_CODE_SPEC.md`](../docs/ARABIC_CODE_SPEC.md)، والمخرجات الحقيقية في [`../docs/DEMO_TRANSCRIPT.md`](../docs/DEMO_TRANSCRIPT.md).

## الإصلاح

| المستوى | ماذا يفعل |
|---|---|
| 0 | حذف الحروف الخفية (اتجاه/صفرية العرض/وسوم) · `، ؛ ٫ ٬` · أرقام عربية في الأعداد · `؟` في الشرط الثلاثي · تطويل · فصل أرقام الالتصاق |
| 1 | + إعادة تسمية متسقة للأسماء (`متغير١` ← `متغير1` في كل مواضعها) |
| 2 | + نموذج لغوي بحلقة تحقق (`--ai` مع `ZAYTUNA_API_KEY`) — ولا يُطبَّق شيء قبل اجتياز المدقّق |

`إصلاح` يحفظ نسخة `.bak` قبل الكتابة، **ويرفض الكتابة** إن لم يستطع التحقق (إلا بـ `--no-verify` الصريحة).
