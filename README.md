## Standalone Android app: Stereo Sound

Stereo Sound is a **native, offline Android app**, not a website or a WebView. Its comic-book interface uses the same cream, ink, red, yellow and cyan palette. It plays locally selected audio and provides balance, channel tests and device-dependent sound effects. It does not alter audio from other apps. Android 6.0+; an iPhone app is not included.

- **Install a test APK without leaving the website:** in the *Mobile app* section press **⬇ نزّل APK وثبّته على هاتفك**. The button opens an in-page install panel and downloads `stereo-sound.apk` through the site's own server (`/api/app/status` + `/api/app/apk`) — it never redirects to GitHub and needs no GitHub sign-in. If no APK has been published yet, the panel stays on the page and offers the Android project ZIP and the browser app instead.
- **Where the APK comes from (in order):** the `STEREO_APK_URL` environment variable if the deployer sets it → a locally built `app/build/outputs/apk/debug/app-debug.apk` → the latest public GitHub Release asset. The `Android — build installable test APK` workflow publishes that release asset (`stereo-test-apk` tag) on pushes to `main`, or on demand via its `publish_release` input. This debug-signed APK is for testing, not a production store release.
- **Build:** `cd site/downloads/stereo-sound && ./gradlew testDebugUnitTest assembleDebug` (JDK 17 and Android SDK 36 required).
- **Release:** a manual workflow can build a release-signed APK and AAB after the owner configures a private signing key as GitHub secrets. Publishing to Google Play is a separate, manual step. See [build and release instructions](site/downloads/stereo-sound/README_BUILD.ar.md).

## 🤖 ZYNQ BOT — شخصية الموقع الحيّة (روبوت ZYNQ FX)

روبوت الموقع الرسمي: نفس الشخصية في الصورة (رأس أبيض لامع، سماعات سوداء بإضاءة، هودي أسود بشعار **ZYNQ FX**)، لكنه **يتحرّك ويتكلّم**. مرسوم بالكامل بـ **SVG** ومحرَّك بـ **CSS** — بلا صورة واحدة، وبلا أي مكتبة.

| ما فيه | التفاصيل |
|---|---|
| **١٠ أوضاع** | وقفة · تحية · إبهام لأعلى · رقصة · تفكير · طيران · عرض · برق · برمجة · نوم — كل وضع حركة مستقلة (ذراع بمرفق مفصول، رأس، أرجل، ملحقات) |
| **١٢ تعبيرًا** | هادئ · سعيد · ضحك · غمزة · قلوب · نجوم · مندهش · تفكير · تحميل · نعسان · خطأ · مركّز — الوجه كله OLED داخل الشاشة مع رمش عشوائي وحركة عين تتبع مؤشر الزائر |
| **صوت روبوت لطيف** | كلام عربي عبر محرّك النطق في الجهاز، وإن لم يتوفر يتحوّل تلقائيًا إلى **لغة الروبوت** (نغمات تُولَّد لحظيًا بـ Web Audio) + ١١ مؤثرًا: تحية، موافقة، ضحكة، خطأ، مسح، تشغيل… **بلا ملفات صوت** ولا إنترنت. الصوت لا يبدأ أبدًا بلا ضغطة، وفيه زر كتم |
| **٦ ألوان متغيّرة** | البنفسجي أساس ثابت (الهوية)، والمتغيّر هو لون التمييز والإضاءة: بنفسجي ملكي · ليلَك نيون · سماوي · زمردي · وردي · غروب — تتغيّر لحظيًا للصفحة كلها |
| **الموقع** | صفحة كاملة احترافية: هيرو، معرض الأوضاع، مختبر حيّ (وضع + تعبير + لون + كتابة جملة يردّها بصوته)، معرض التعبيرات، شرح الصوت، وكود الدمج |
| **في الصفحة الرئيسية** | قسم «ZYNQ BOT» مع روبوت حيّ + رفيق عائم في الزاوية يتفاعل مع الزائر (بلا صوت تلقائي) |

- **الصفحة:** `http://localhost:4173/bot/` · **الملفات:** [`site/public/bot/`](site/public/bot)
- **الدمج في أي صفحة** (٣ أسطر):

```html
<link rel="stylesheet" href="/bot/bot.css">
<div id="my-bot"></div>
<script src="/bot/bot-engine.js"></script>
<script>
  const bot = ZynqBot.mount(document.querySelector('#my-bot'), {
    pose: 'wave', expression: 'happy'   // أي وضع/تعبير من القائمتين
  });
  bot.say('أهلًا بك في ZYNQ FX!');       // عربي إن توفر، وإلا لغة الروبوت
  ZynqBot.applyTheme('cyan');            // لون التمييز (البنفسجي يبقى الأساس)
</script>
```

- **الواجهة البرمجية:** `ZynqBot.mount(el, opts)` ← `setPose / setExpression / say / wave / react / destroy` · `ZynqBot.voice.speak/sfx/setMuted/mode` · `ZynqBot.applyTheme(id)` · `ZynqBot.POSES / FACES / THEMES`
- **بلا فوتوشوب:** الشخصية متجهية، حادّة من ٤٤ بكسل إلى 4K، وتعمل بلا إنترنت وبلا مكتبات خارجية.
- **الأداء والإتاحة:** الحركات كلها CSS (تُنفَّذ على مركّب الرسوم)، حركات بطاقات المعرض متوقفة حتى المرور أو التركيز، ودعم كامل لـ `prefers-reduced-motion`.
- **الفحص:** `node tests/site-check.js` — يشمل الآن **٣٨ فحصًا خاصًا بالروبوت**: كل وضع يُنتج SVG متوازنًا، كل تعبير يرسم عينه وفمه، كل `animation` له `@keyframes` موجود، الصوت بلا ملفات وبلا تشغيل تلقائي، وكل عنصر يستخدمه السكربت موجود في HTML.

## الأدوات السابقة في المستودع: «زيتونة» — لغة برمجة عربية + مصحّح أكواد

برنامج يكتب الكود، **ويصلح الأخطاء تلقائيًا**، ويدعم **لغات كثيرة**، مع **لغة برمجة عربية** كنقطة التميّز.
النموذج الأولي في [`zaytuna/`](zaytuna) — **عامل اليوم: 83/83 اختبارًا ناجحًا، و17 لغة مدعومة، وترجمة إلى 11 لغة هدف بثلاث طبقات تحقق معلنة**، والأوامر كلها بالعربية.

| الملف | المحتوى |
|---|---|
| [`docs/ARABIC_CODE_SPEC.md`](docs/ARABIC_CODE_SPEC.md) | المواصفة الكاملة: اللغة والمعجم، المصحّح بثلاثة مستويات وضمان التحقق، 46 رمز تشخيص عربي (أمان، ترقيم، أرقام، أنماط، أنواع)، خارطة اللغات، النموذج الربحي، خارطة 12 شهرًا، المخاطر، المصادر |
| [`docs/DEMO_TRANSCRIPT.md`](docs/DEMO_TRANSCRIPT.md) | **مخرجات حقيقية**: تشغيل برامج عربية، فحص ملفات بها أخطاء، إصلاح تلقائي في JS وPython، ونتيجة التحقق |
| [`docs/zaytuna-presentation.html`](docs/zaytuna-presentation.html) | عرض بصري (افتحه في المتصفح) |
| [`zaytuna/`](zaytuna) | الكود: المترجم (أنماط + أنواع + أدوية عامة) + المصحّح + الحارس + **زر الترجمة** + الاختبارات + جولة العرض |

### الخلاصة السريعة

- **الفكرة في سطر:** العربية مدعومة في اللغات أصلًا (الأسماء العربية تعمل في JS وPython!)، لكن أحدًا لا يبني أدوات لها؛ وأخطاء «العربية» (رقم هندي في عدد، فاصلة عربية، حرف اتجاه مخفي) تُنتج أخطاء غامضة — هنا الفجوة.
- **اللغة «زيتونة»:** عربية الوجه، **تُترجم 1:1 إلى جافاسكربت** — جسر لا جزيرة، لذلك كل مكتبات npm تعمل فورًا (وهو الدرس من موت «قلب» 2013).
- **تصريف ذاتي فعلي:** أول جزء من الأداة (مقترح الكلمات المفتاحية) **مكتوب بلغة زيتونة** ويُنفَّذ داخل الأداة: `zaytuna اقترح طالم` ← «طالما» — ومُختبَر على 229 مدخلًا مقابل تنفيذ جافاسكربت (0 اختلافات).
- **المصحّح:** ثلاثة مستويات (حتمي ← قواعد لغوية ← نموذج لغوي)، و**قاعدة مقدّسة: لا يُكتب أي إصلاح قبل اجتيازه مدقّق اللغة الحقيقي** (`node --check` / `py_compile` / مترجم زيتونة)، وإن فشل نقول ذلك ولا نكتب شيئًا.
- **الحارس الأمني:** أول أداة عربية تقرأ أحرف الاتجاه المخفية (Trojan Source / CVE-2021-42574) وترفعها خطرًا أمنيًا — وهذا ما لا يفعله أي مصحّح في السوق.
- **17 لغة:** جافاسكربت · تايبسكربت · بايثون · زيتونة · سي · سي++ · جافا · سي شارب · جو · رست · بي إتش بي · روبي · شل · بيرل · سويفت · كوتلن · SQL — بمُدقّق حقيقي لكل لغة، وسبع منها مُتحقَّق منها في هذه البيئة فعلًا (JS · Python · زيتونة · C · C++ · Shell · Perl). وكل لغة بلا مدقّق مثبّت: نقولها ولا نكتب إصلاحًا.
- **لغة موسّعة:** **أنماط مطابقة** `طابق (ق) { مع ١، ٢: … مع من ٤ إلى ١٠: … مع [أ، ب]: … غير_ذلك: … }` · **أدوية عامة وأنواع عربية تُشطب في JS وتبقى مع `--ts`** · شرط ثلاثي عربي `؟ … :` · `اختر/حالة` · `انشر` (بسط) · دوال سهمية · `الأصل` · `احذف` · أدوات نصية عربية.
- **زر الترجمة (11 هدفًا):** اكتب بالعربية ثم اختر اللغة الهدف. **الطبقة 1 — مترجم حقيقي:** جافاسكربت · بايثون · سي++ · سي (يُفحص بمترجم اللغة، **ويُشغَّل فعلًا**، وتُقارن نتيجته بجافاسكربت — تطابق حرفي في أمثلة الاختبار). **الطبقة 2 — فحص بنيوي:** تايبسكربت · روبي · بي إتش بي · جافا · سي شارب · جو · رست (تُبنى شجرة الصياغة الرسمية للغة بقواعد tree-sitter، ويُقال بصراحة: **«فحص بنيوي — وليس تحققًا بمترجم»**، لأن المترجم غير مثبّت على هذا الجهاز). **الطبقة 3:** «لم نتحقق» + السبب. وما لا يمكن ترجمته في أي لغة يُعلن صريحًا. ومن الواجهة: `node ui/server.js` (قائمة لغات + زر «ترجم»)، ومن الطرفية: `zaytuna ترجم ملف.zy --إلى بايثون`.
- **جرّبه:** `cd zaytuna && node tests/run.js && bash demo/tour.sh` (وللترجمة: `node ui/server.js`) (ولسجلّ المخرجات الحقيقية: `node demo/make-transcript.js`)
- **النشر على فيرسل:** الواجهة تعمل محليًا كخادم عادي (`node ui/server.js`) وعلى فيرسل كدالة بلا خادم بنفس الملف — `vercel.json` في جذر المستودع (و`zaytuna/vercel.json` إن كان Root Directory هو `zaytuna`) يوجّه كل المسارات إلى `ui/server.js`. اربط المستودع واترك إعدادات البناء فارغة؛ إن ظهر 404 فتأكد أن الملف المصدّر هو `ui/server.js`.
