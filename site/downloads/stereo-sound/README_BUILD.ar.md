# بناء تطبيق «ستيريو — صوت استيريو» (Stereo Sound)

هذا المجلد يحتوي على كود مصدر برنامج أندرويد بلغة **كوتلين (Kotlin)** يحول إخراج صوت الهاتف إلى **استيريو (قنوات يمين/يسار)** حتى مع الملفات الصوتية الأحادية، مع موازن استيريو ومعادل صوتي مدمج.

## ما في هذا المجلد

| المسار | المحتوى |
|---|---|
| `stereo-sound.apk` | إصدار تجريبي **(غير موقع / dev preview)** للتجربة السريعة. |
| `app/src/main/...` | كود المصدر الكامل للتطبيق (كوتلين + موارد أندرويد). |
| `build.gradle.kts`, `settings.gradle.kts` | ملفات بناء غرادل (Gradle) لمشروع Android Studio. |

## ملاحظات هامة حول ملف الـ APK

ملف `stereo-sound.apk` الموجود هنا هو **بناء تجريبي غير موقّع** لأن هذا المستودع لا يحتوي على سلسلة أدوات أندرويد (جافا/غرادل). على إصدارات أندرويد الحديثة، لا يمكن تثبيت ملفات APK غير الموقّعة عبر نقل الملف فقط.

لحصول على ملف APK يمكن تثبيته ونشره:

1. افتح مجلد `stereo-sound/` في **Android Studio** (File → Open).
2. انتظر مزامنة غرادل.
3. اختر **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk` (موقّع بمفتاح تصحيح الأخطاء وقابل للتثبيت عبر `adb install` أو نقله وتثبيته على الهاتف).
5. للإصدار النهائي: أضف إعداد `signingConfig` في `app/build.gradle.kts` أو استخدِم **Generate Signed Bundle / APK** من قائمة Build.

إذا كنت تشغّل من سطر الأوامر وتحتاج إلى ملف الغلاف (`gradlew`):
```
gradle wrapper   # يحمّل ملف جافا-wrapper الخاص بغرادل مرة واحدة
./gradlew assembleDebug
```
(تحتاج إلى تثبيت جافا JDK 17 وغرادل 8.2 على جهازك.)

## ماذا يفعل البرنامج

- يُفعّل إخراج الصوت स्टीरियो (قنوات يمين ويسار) عبر `AudioTrack` بتنسيق `CHANNEL_OUT_STEREO`.
- يصوّت إشارة أحادية إلى قناتين مع موازن يمين/يسار قابل للتعديل.
- معادل صوتي (Equalizer) على جلسة المخرج عند توفّره من النظام.
- يعمل كخدمة في الخلفية (`StereoService`) مع الإذن بتعديل إعدادات الصوت (`MODIFY_AUDIO_SETTINGS`).

## الأذونات

- `android.permission.MODIFY_AUDIO_SETTINGS` — لتوجيه مخرج الصوت إلى وضع الاستيريو.
- `android.permission.RECORD_AUDIO` — للمعالجة المستقبلية للإدخال الصوتي.
