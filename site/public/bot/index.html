للمطوّرين

أضف الروبوت إلى أي صفحة

محرّك واحد بلا تبعيات: أضف ملف المحرّك وملف الأنماط، ثم استدعِ ZynqBot.mount.

<link rel="stylesheet" href="/bot/bot.css">
<div id="my-bot"></div>
<script src="/bot/bot-engine.js"></script>
<script>
  // شخصية كاملة: وضع + تعبير
  const bot = ZynqBot.mount(document.querySelector('#my-bot'), {
    pose: 'wave',          // stand | wave | thumbs | dance | think
                            // fly | present | bolt | typing | sleep
    expression: 'happy',    // idle | happy | laugh | wink | love | star
                            // surprised | think | loading | sleep | error | cool
    mini: false, alive: true
  });

  // يتكلّم: عربي إن توفّر، وإلا لغة الروبوت
  bot.say('أهلًا بك في ZYNQ FX!');

  // لون التمييز + الإضاءة (البنفسجي أساس دائمًا)
  ZynqBot.applyTheme('cyan');
</script>

لماذا يعمل في كل مكان

  • ◆بلا مكتبات: ملف JS واحد + CSS واحد — لا React ولا Three.js ولا صور.
  • ◆حادّ في كل المقاسات: رسم SVG متجهي من 44 بكسل إلى 4K.
  • ◆أداء هادئ: حركات CSS فقط (يُشغّلها مركّب الرسوم)، والصوت يُنشأ عند الطلب.
  • ◆إتاحة: عناوين وصفية، دعم prefers-reduced-motion، والكلام لا يبدأ تلقائيًا.
  • ◆البنفسجي أولًا: ستة ألوان تمييز متغيّرة كلها متوافقة مع البنفسجي — لا تكسر الهوية.
