## الخلاصة العملية

| ما رأيته | الحالة |
|---|---|
| لغة عربية تُنفَّذ فعليًا (دوال، أصناف، حلقات، دوال مبدية) | ✅ يعمل |
| ترجمة إلى جافاسكربت + خريطة أسطر + تعليقات محفوظة | ✅ يعمل |
| تشخيصات عربية بموضع دقيق + اقتراح إصلاح | ✅ يعمل |
| كشف أحرف الاتجاه المخفية (Trojan Source) | ✅ يعمل |
| إصلاح تلقائي للجافاسكربت (أرقام عربية، ترقيم عربي، حروف مخفية) | ✅ يعمل |
| إصلاح تلقائي لبايثون (أرقام عربية) | ✅ يعمل |
| **ضمان:** لا يُكتب أي إصلاح قبل اجتيازه مدقّق اللغة الحقيقي | ✅ مفروض برمجيًا |
| إصلاح بنموذج لغوي (المستوى 2) | ⏳ واجهة + حلقة تحقق جاهزتان — تحتاج مفتاح API |

> إصلاح المستوى 2: `zaytuna إصلاح ملف --ai` (مع `ZAYTUNA_API_KEY`) — ولا يُطبَّق شيء قبل اجتياز التحقق، وإن فشل النموذج نقول ذلك صراحة ولا نكتب شيئًا.
