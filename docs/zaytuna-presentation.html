02المنتج في ثلاثة أجزاء — كلها تعمل اليوم

① لغة «زيتونة»

نحو عربي طبيعي (متغير · دالة · أرجع · طالما)، فاصلة منقوطة اختيارية، ترقيم عربي مقبول، أرقام هندية تُحوَّل تلقائيًا، ونصوص بعلامات «…».

تُترجم إلى جافاسكربت خريطة أسطر تعليقات محفوظة

② المصحّح التلقائي

ثلاثة مستويات: حتمي (حروف مخفية وأرقام وترقيم) ← قواعد لغوية (إعادة تسمية متسقة) ← نموذج لغوي بحلقة تحقق. يعمل على ملفاتك أنت في جافاسكربت وبايثون، لا على لصق في متصفح.

إصلاح + تحقق إلزامي نسخة احتياطية

③ حارس اليونيكود

يكشف أحرف الاتجاه المخفية (هجوم يعرض الكود معكوسًا عمّا ينفّذه المترجم)، وحروف الحقن صفرية العرض، والأسماء المتشابهة متغير١ / متغير1.

نحن أول من تقرأ هذه الأحرف فعلًا

03اللغة: كود عربي حقيقي ← جافاسكربت

تكتب (زيتونة)

# حاسبة صغيرة
دالة صنّف(العدد) {
  إذا (العدد > 10) { أرجع "كبير" }
  وإلا { أرجع "صغير" }
}

ثابت الأعداد = [١، ٢، ٣، ٤، ٥]   # أرقام هندية ← تُحوَّل
متغير المجموع = 0
لكل عدد في الأعداد { المجموع += عدد }
اطبع("المجموع = " + المجموع + " — " + صنّف(المجموع))

يُنفَّذ (جافاسكربت مولَّد)

// حاسبة صغيرة
function صنّف(العدد) {
  if (العدد > 10) { return "كبير"; }
  else { return "صغير"; }
}

const الأعداد = [1, 2, 3, 4, 5];
let المجموع = 0;
for (const عدد of الأعداد) { المجموع += عدد; }
console.log("المجموع = " + المجموع + " — " + صنّف(المجموع));

مخرجات التشغيل الحقيقية: المجموع = 15 — كبير — والخريطة تحفظ السطر العربي ↔ السطر المولَّد (لتشخيص دقيق في المحرر لاحقًا).

لماذا هذا مهم؟ لأن كل مكتبات العالم (npm) تعمل معها فورًا: اللغة عربية الوجه، ونظامية القلب. لا «جزيرة برمجية» جديدة بلا مكتبات كما حدث للغات العربية السابقة.

مستوى 0 — حتمي

حروف مخفية · أرقام عربية في الأعداد · ، ؛ ٫ ٬ · ؟ في الشرط الثلاثي · تطويل. يُطبَّق بلا سؤال بعد التحقق.

05الحارس الأمني: الميزة التي لا يملكها أحد غيرنا

هجوم Trojan Source — كيف يبدو

سطران يبدوان متطابقين، والمترجم ينفّذ شيئًا آخر — لأن حرف اتجاه مخفي (U+202E) يقلب العرض. رست 1.56 صارت ترفضها، فكّرت المنصّات أن الحل هو إظهارها للمراجعين.

// كما يراه المراجع:
if (access_level != "user‮  ‮// Check if admin") { … }

// زيتونة تقول:
⛔ خطر أمني Z101 — السطر 13، العمود 6: حرف اتجاه مخفي (Bidi): U+202E
   ↳ الإصلاح المقترح: احذفه
   ⓘ يقلب اتجاه عرض السطر فيظهر الكود معكوسًا عمّا ينفّذه المترجم

ما يكشفه في ملف واحد

  • Z101 — أحرف الاتجاه (خطر أمني في الكود، تحذير داخل النصوص)
  • Z102/Z104/Z105 — صفرية العرض · وسوم الحقن · حروف التحكّم
  • Z208 — رقم عربي داخل اسم: متغير١ يشبه متغير1
  • Z211/Z212 — أرقام هندية وفواصل عربية في الأعداد (أخطاء فعلية)
  • Z213 — ؟: تُصلح فقط لو كانت شرطًا ثلاثيًا، وإلا تُترك بقرار بشري
  • Z214 — خلط ي/ى أو ك/ک أو ه/ة في اسم واحد
  • Z401 — فشل مدقّق اللغة، مشروحًا بالعربية

10المخاطر — بصراحة كاملة

  • «لعاطفة عربية تُنسى بعد أسبوعين»: العلاج — المنتج يبيع ألمًا يوميًا (أخطاء حقيقية + حارس أمني)، لا هوية فقط.
  • منافس غربي يضيف دعمًا عربيًا: العلاج — خندقنا المعجم والنحو العربي؛ قائمة أحرف تُنسخ، وتصميم لغة لا يُنسخ في أسبوع.
  • إصلاح خاطئ يهدم الثقة: العلاج — تحقق إلزامي + نسخة احتياطية + شفافية كل تغيير + «لا نكتب شيئًا» عند الفشل.
  • تشتّت الجهد بين لغات كثيرة: العلاج — لغة كاملة واحدة (JS) + بايثون، ثم مدقّق واحد كل مرحلة بشروط تحقق.
  • «مجرد لعبة أكاديمية»: العلاج — أرقام: 44 اختبارًا + تكامل مع اللغات الحقيقية + ضمان التحقق + حالة استخدام تجارية (CI).
