# مساعد زينك العربي — الإصدار 2.0

## ما الذي تغيّر فعليًا؟

- العربية هي لغة الواجهة والردود ووضع النطق الافتراضي.
- إصلاح طلب قائمة الملفات: `/files/files.json` بدل المسار القديم غير الموجود داخل `/files-bot/`.
- دمج أصول المكتبة الرئيسية في المساعد دون تكرار الملفات: 100 ملف أساسي + 50 مؤثرًا = 150 ملفًا.
- إضافة 16 أصلًا جديدًا: 8 Lottie و8 SVG للترحيب والتفكير والحديث والتحميل والنجاح والكتابة والاحتفال والتنبيه.
- معاينة Lottie من JSON الأصلي بمشغّل محلي، ومعاينة SVG وGIF والصور والنصوص، وصوت يعمل بضغط المستخدم فقط.
- بحث يتجاهل التشكيل ويوحّد الألف والياء، مع تصنيف وترتيب وصفحات وحالة «لا نتائج» وإعادة محاولة عند فشل التحميل.
- تنزيل الملف الأصلي بعد التحقق من استجابة الخادم، مع اسم الملف وامتداده الصحيحين. لا ندّعي أن المتصفح أكمل الحفظ على القرص.
- إصلاح منحنيات keyframes في مولّد Lottie حتى تظهر الطبقات المتحركة فعلًا في مشغّل lottie-web.
- دعم إيقاف الحركة، وتقليل الحركة في النظام، ولوحة معاينة تحصر التركيز وتغلق بـ Escape.

## الصوت العربي على جهازك

يستخدم البوت `speechSynthesis` المحلي. وجود واجهة عربية لا يعني أن كل نظام يحتوي صوتًا عربيًا مثبتًا:

1. ثبّت صوتًا عربيًا في إعدادات النطق/إمكانية الوصول في نظامك. تختلف الخطوات حسب Android أو iOS أو Windows أو macOS وتوزيعات Linux.
2. افتح الصفحة في متصفح يدعم Web Speech وأعد تحميلها.
3. افتح «إعدادات الصوت العربي»، واضغط «تحديث الأصوات»، ثم اختر الصوت.
4. اضغط «جرّب نطق جملة». المصرية `ar-EG` تُفضّل تلقائيًا إن كانت موجودة، ثم `ar-SA`، ثم أي صوت عربي.
5. إذا لم يظهر صوت، يبقى الرد مكتوبًا بالعربية مع توضيح السبب. لا يوجد انتقال خفي للإنجليزية، ولا تُقدّم النغمات على أنها كلام عربي.

وضع «لغة الروبوت» نغمات اختيارية منفصلة. كتم الصوت محفوظ محليًا، ولا يُنشط الميكروفون ولا تُرسل الجمل إلى خدمة ذكاء اصطناعي خارجية. المساعد الحالي مبني على قواعد محلية للبحث والإرشاد، وليس نموذج دردشة عام.

## الملفات والمسارات

| الملف | الوظيفة |
|---|---|
| `site/public/bot/bot-engine.js` | الشخصية، اختيار الصوت العربي، أحداث النطق، الكتم ودورة حياة الحركة |
| `site/public/bot/voice-controls.js` | قائمة الأصوات وحالة النطق وأزرار الاختبار والكتم المشتركة |
| `site/public/bot/preview.js` | معاينات محلية مع إيقاف واستئناف وتنظيف الموارد |
| `site/public/files-bot/` | صفحة المساعد والمحادثة والبحث والتنزيل |
| `site/public/files/files.json` | بيان الملفات والأحجام الحقيقية |
| `site/public/catalog.json` | كتالوج المؤثرات، ومنها 16 أصلًا للبوت |
| `site/downloads/bot/` | ملفات Lottie وSVG الجديدة |
| `site/public/vendor/lottie-5.13.0.min.js` | مشغّل Lottie المحلي، وترخيص MIT بجانبه |
| `tools/gen_bot_assets.py` | إعادة توليد الحركات الجديدة وتحديث الكتالوج |
| `tools/gen_files.py` | إعادة توليد الملفات الأساسية ودمج الكتالوج في بيان المساعد |

## التشغيل والفحص

```bash
npm ci
npm start
# الصفحة: http://localhost:4173/files-bot/
npm test
npm run test:bot

# مرة واحدة لتجهيز متصفح الاختبار:
npx playwright-core install chromium
npm run test:browser
# لمتصفح مثبت مسبقًا:
CHROMIUM_EXECUTABLE=/path/to/chromium npm run test:browser
```

يمكن تحديد `CHROMIUM_LIBRARY_PATH` لمكتبات متصفح محلية عند الحاجة. لقطات فحص المتصفح تُكتب في `.browser-test-artifacts/` المستثناة من Git.

إعادة توليد الأصول الجديدة والبيان:

```bash
npm run assets:bot
npm test
```

لتحديث المكتبة الأساسية كلها، شغّل `python3 tools/gen_files.py` بعد تعديل مولّداتها. لا تحتاج معاينة المساعد إلى اتصال بخادم خارجي؛ المشغّل والخطوط والأصول كلها ملفات محلية.

## النشر وتجنّب النسخة القديمة

- رقم الإصدار ظاهر في الصفحة: **2.0**، وإصدار الحزمة `2.0.0`.
- روابط ملفات البوت والمساعد تحمل `?v=2.0.0`، وخادم الموقع يرسل `Cache-Control: no-store`.
- إعداد Vercel الحالي يضمّن `site/public/**` و`site/downloads/**`، لذا تدخل ملفات المؤثرات والمشغّل والبيان في النشر.
- المسار `/files-bot` يعيد التوجيه إلى `/files-bot/` كي تعمل الروابط النسبية.
- بعد دمج التغيير في فرع النشر، انتظر اكتمال بناء الاستضافة ثم افتح `/files-bot/`. تحقق من شارة الإصدار 2.0 ومن عدد الملفات 150. لا يكفي حفظ التغيير على فرع جانبي لتحديث موقع مبني من `main`.
